# 平衡訓練：同時保持COCO-Pose性能和提升瑜伽姿勢識別能力

此專案提供了一種透過三階段漸進式微調策略，同時保持COCO姿態檢測能力和提升瑜伽姿勢識別能力的解決方案。避免了傳統遷移學習中常見的"災難性遺忘"問題。

## 問題描述

在僅使用瑜伽數據集微調COCO預訓練模型時，我們觀察到以下問題：

- **災難性遺忘**：在瑜伽數據集上的性能顯著提高，但在原始COCO數據集上的性能急劇下降
  - COCO: AP50從0.773降至0.401，AP50-95從0.430降至0.143
  - Yoga: AP50從0.414提升至0.797，AP50-95從0.146提升至0.432

## 解決方案: 三階段漸進式微調

我們設計了一個三階段訓練流程，使用混合數據集和精心調整的超參數：

1. **COCO記憶刷新階段**：
   - 在COCO數據集上短期訓練以刷新模型記憶
   - 使用低學習率避免改變太多預訓練知識
   
2. **混合數據平衡訓練階段**：
   - 混合COCO和瑜伽數據集進行訓練
   - 平衡的損失權重和數據增強策略
   - 適當凍結少量早期層保留基礎特徵

3. **精細微調階段**：
   - 在混合數據集上進行最終精細調整
   - 極低學習率和線性學習率衰減
   - 關閉大部分數據增強以專注於精細調整

## 開始使用

### 安裝依賴

```bash
pip install ultralytics
```

### 準備數據集

1. 確保您的數據集結構正確：
   ```
   datasets/
   ├── coco-pose/
   │   ├── train2017/
   │   ├── val2017/
   │   ├── train2017.txt
   │   └── val2017.txt
   └── yoga82/
       ├── images/
       │   ├── train/
       │   └── val/
       └── labels/
           ├── train/
           └── val/
   ```

2. 確保已存在以下配置文件：
   - `yoga82.yaml` - 瑜伽數據集配置
   - `mixed_coco_yoga.yaml` - 混合數據集配置（已提供）
   - 在ultralytics安裝目錄中的`coco-pose.yaml`

### 運行訓練

使用提供的平衡訓練腳本：

```bash
python train_balanced.py --model yolov8x-pose.pt --device 0,1,2,3 --batch 32
```

### 參數說明

- `--model`: 初始模型路徑（默認: yolov8x-pose.pt）
- `--device`: 訓練設備（默認: 0,1,2,3，使用前四個GPU）
- `--batch`: 批次大小（默認: 32）
- `--save-dir`: 保存目錄（默認: runs/pose/balanced_training）
- `--skip-stage`: 跳過前N個階段（默認: 0，執行所有階段）

### 僅執行特定階段

如果您想從特定階段開始訓練，可使用`--skip-stage`參數：

```bash
# 從第二階段開始（跳過第一階段）
python train_balanced.py --model /path/to/stage1_model.pt --skip-stage 1

# 只執行第三階段（跳過前兩階段）
python train_balanced.py --model /path/to/stage2_model.pt --skip-stage 2
```

## 結果

成功的訓練應在兩個數據集上都達到良好的性能，例如：

- **COCO-Pose**:
  - Box mAP50: ~0.700+ (原始0.773)
  - Pose mAP50-95: ~0.350+ (原始0.430)
  
- **Yoga82**:
  - Box mAP50: ~0.900+ (改進前0.786)
  - Pose mAP50-95: ~0.380+ (改進前0.146)

## 注意事項

- 訓練時間較長，三階段總共約40個epochs
- 建議使用具有足夠GPU內存的機器(>10GB)，特別是對於大型模型(如yolov8x-pose)
- 混合數據集的權重調整可能需要基於您特定任務的重要性進行調整

## 進階使用

### 修改COCO和瑜伽數據權重

如需調整兩個數據集的相對重要性，請修改`mixed_coco_yoga.yaml`中的`instance_weights`值：

```yaml
instance_weights:
  - 0.3  # COCO訓練集權重
  - 0.7  # Yoga82訓練集權重
```

### 自定義訓練參數

您可以直接編輯`train_balanced.py`中的各階段訓練函數參數，根據您的需求調整：

- 學習率和調度
- 損失權重
- 數據增強設置
- 凍結層數量等

## 故障排除

- **內存不足**: 減小批次大小或使用較小的模型(如yolov8m-pose)
- **訓練不穩定**: 檢查學習率設置，可能需要降低`lr0`值
- **COCO性能仍低**: 增加第一階段的訓練週期，或減小混合數據集中瑜伽數據的權重
